# Shashi-Usb-Media v1.0

Replacement `MainActivity.kt` for the existing Shashi-Usb-Media project.

Included:
- Android system Back button navigation
- Separate Internal Memory and External SSD/USB rooms
- Persistent SSD/USB tree permission
- Recursive external-drive scan
- Real video-frame thumbnails
- Photo thumbnails and zoom
- Video playback with Media3
- Grid/list media browser
- Search and file sizes
- MIME + filename extension detection for SSD files

Replace:
`app/src/main/java/com/shashi/mediaviewer/MainActivity.kt`

with the included file, then run the existing GitHub Actions workflow.
